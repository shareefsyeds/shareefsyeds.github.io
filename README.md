# shareefsyeds.github.io

Source for [shareefsyeds.github.io](https://shareefsyeds.github.io). Built with Astro, deployed to GitHub Pages by the workflow in `.github/workflows/deploy.yml`.

```sh
npm install
npm run dev     # http://localhost:4321
npm run build   # static output in dist/
```

Case studies live in `src/content/work/` as Markdown. Work without a write-up yet is listed in `src/data/site.ts`.
